HOMERA LIVING WEBSITE SOURCE

Files:
- index.html: website structure and embedded logo
- styles.css: styling and responsive layout
- script.js: product rendering, navigation, support modal, form validation and thank-you flow
- assets/homera-living-logo.png: logo image source (also embedded in index.html)

To run: open index.html in a modern browser. Product images load from Unsplash and require an internet connection.

Note: this is a front-end demo. The support form does not submit to Salesforce or a backend yet.

Separate thank-you page: thank-you.html. The support form redirects to this page after submission.
